# Retro Bowl — external game link

This GitHub Pages project provides a simple landing page linking to the third-party Retro Bowl browser-game mirror maintained at [3kho/retro-bowl](https://github.com/3kho/retro-bowl).

**Play link:** https://3kh0.github.io/retro-bowl/

**This repository does not host or redistribute Retro Bowl's game files.** The external game is not an official GitHub mirror maintained by New Star Games. No mod or cheats are included in this landing page.

## Deploy

In this repository, go to **Settings → Pages → Build and deployment** and choose **Deploy from a branch**, then select **main** and **/(root)**. Once GitHub Pages completes deployment, the landing page should appear at:

https://weixianpig.github.io/pixel-gridiron/

## Existing files

The previously created original Pixel Gridiron prototype files remain in the repository for reference; they are not loaded by the current homepage.
